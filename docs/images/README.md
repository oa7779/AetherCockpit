# Produktbilder

Dieser Ordner enthält aktuell geprüfte AETHER-Aufnahmen, die aus dem
Beta-53-Produktstand stammen und in der öffentlichen README verwendet
werden.

| Datei | Inhalt |
|---|---|
| `aether-logo.png` | Proportional verkleinerte Kopie des kanonischen Repository-Logos |
| `00-neon-wave-boot.png` | Reales AETHER-Bootfenster im Retro-Neon-Modus |
| `02-system-overview.png` | AETHER-Systemübersicht mit Livewerten |
| `03-mainboard.png` | Mainboard- und Hardwareansicht mit synthetischen Testdaten |
| `04-aether-intelligence.png` | AETHER Intelligence mit Modell- und Validierungsbereich |
| `05-local-ai-setup.png` | AETHER Local AI Setup mit Phi-4-Mini-Pfad |
| `06-guardian.png` | Guardian-Arbeitsbereich mit synthetischen Testdaten |
| `07-intelligence-evidence.png` | Findings und technische Prüfinformationen aus AETHER Intelligence |
| `08-aether-server-demo.png` | Serververwaltungsoberfläche mit 48 synthetischen Testgeräten |

Das Bootbild wurde nur auf das vollständige AETHER-Fenster zugeschnitten;
Inhalte, Farben und innerer Bildbereich wurden nicht verändert. Synthetische
Daten in Mainboard-, Guardian- und Serveransichten sind in der README als
solche gekennzeichnet. Frühe Boot-Aufnahmen mit Fehlerdialog und fremde
Screenshots wurden nicht übernommen.
