# Produktbilder

Dieser Ordner enthält aktuell geprüfte AETHER-Aufnahmen, die aus dem
Beta-53-Produktstand stammen und in der öffentlichen README verwendet
werden.

| Datei | Inhalt |
|---|---|
| `aether-logo.png` | Proportional verkleinerte Kopie des kanonischen Repository-Logos |
| `01-aether-neon-wave-boot.png` | Reales AETHER-Bootfenster im Retro-Neon-Modus |
| `02-system-overview.png` | AETHER-Systemübersicht mit Livewerten |
| `04-aether-intelligence.png` | AETHER Intelligence mit Modell- und Validierungsbereich |

Das Bootbild wurde nur auf das vollständige AETHER-Fenster zugeschnitten;
Inhalte, Farben und innerer Bildbereich wurden nicht verändert. Frühe
Boot-Aufnahmen mit Fehlerdialog, synthetische Testbilder und fremde
Screenshots wurden bewusst nicht übernommen. Für Bereiche ohne aktuelle,
passende Aufnahme enthält die README keinen Platzhalter.
